# Project Invariants

completeness_level: complete

status: validated

## Purpose
This document defines the invariant boundaries for growth and keeps the project aligned to truthful ownership of runtime responsibilities.

## Applicability
This document applies to the repository itself and to any local project code, documentation, or operational flow that is intentionally owned by the repo.

## Invariants
- preserve honest project ownership and avoid fake runtime dependencies
- keep the adoption profile aligned with actual code and doc reality
- maintain traceability across goal, task, execution plan, and validation records
- prefer explicit `not-applicable` decisions over invented operational claims

## Exceptions
Any exception must be approved and recorded in the project owner documentation, with an explicit reason and validation evidence.

## Review cadence
This file should be reviewed at project major milestones and before any significant onboarding or runtime-scope change.
