# Constitution

completeness_level: complete

## Purpose
This constitution defines the project boundary for growth and asserts that adoption documents remain truthful, reviewable, and aligned with the actual service scope.

## Constitutional principles
- keep project intent honest and specific to the repository that owns it
- prefer truthful `not-applicable` capability decisions over invented runtime constraints
- maintain traceability from project goals to execution plans to validation evidence
- respect the central IPS authority while keeping repo-local intent in the project itself

## Amendment process
Any amendment to the working constitution must be reviewed by the project owner and reflected in the relevant project documents before it is treated as current practice.
